# Code of Conduct

## Our commitment

We are committed to maintaining an open, respectful and professional environment for everyone who participates in the WorknoiseR project.

Participants are expected to communicate constructively, respect different professional and academic perspectives, and focus discussion on improving the software, documentation and occupational-noise assessment workflows.

## Expected behaviour

- Use respectful and professional language.
- Provide technical criticism constructively.
- Respect differences in experience, discipline, background and viewpoint.
- Report bugs and methodological concerns with enough detail to support reproducibility.
- Avoid harassment, discrimination, personal attacks and disruptive behaviour.

## Scope

This Code of Conduct applies to the WorknoiseR repository, issues, pull requests, discussions and other project communication spaces.
